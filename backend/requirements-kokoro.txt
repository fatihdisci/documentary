# Kokoro — the local, offline narration voice, and the default TTS provider.

#   ./dev.sh --setup --no-kokoro   skips it
#   pip install -r backend/requirements-kokoro.txt    add it later
#
# The model weights themselves (~350 MB) are not here: Kokoro downloads them
# from Hugging Face on first use and caches them under ~/.cache/huggingface.
